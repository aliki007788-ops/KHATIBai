# گزینه الف — تکمیل‌های سبک

## انجام‌شده

1. **UI مدیریت لینک اشتراک** در `/practice/[id]`
   - ساخت/تمدید لینک با انقضا (۱/۳/۷/۳۰ روز)
   - نمایش یا مخفی‌کردن رونوشت
   - کپی لینک
   - لغو لینک
   - نمایش وضعیت فعال/منقضی

2. **یادآور تمرین در داشبورد**
   - بنر `reminder_message` از API
   - دکمه مستقیم «تمرین الان»
   - چالش روزانه با progress bar

3. **مدیریت محتوا ادمین**
   - سطوح و سناریوها از API واقعی learning
   - واژگان با CRUD محلی (localStorage)

4. **تنظیمات ادمین**
   - ذخیره تنظیمات در localStorage و بازیابی هنگام بارگذاری

5. **چندزبانگی**
   - زبان پیش‌فرض تمرین از `languageStore` (تنظیمات حساب)

## دیپلوی

همان مایگریشن مرحله ۱ کافی است اگر قبلاً `alembic upgrade head` زده‌اید.
فقط فرانت را redeploy کنید (و در صورت نیاز بک‌اند را restart).
